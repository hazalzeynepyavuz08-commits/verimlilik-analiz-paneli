#Haftalık Çalışma ve Verimlilik Analiz Paneli

Python, Pandas, Plotly ve Streamlit kullanarak geliştirdiğim interaktif veri analizi ve görselleştirme paneli.

##Özellikler
- **Dinamik Filtreleme:** Sol menüden seçilen derslere göre tüm verilerin anlık güncellenmesi.
- **Özet Metrikler (KPI):** Toplam çalışma saati, ortalama odak puanı ve ortalama uyku süresi hesaplaması.
- **İnteraktif Grafikler:** Ders bazlı çalışma saatleri (çubuk grafik) ve günlük odak değişimi (çizgi grafik).
- **Veri Tablosu:** Filtrelenmiş ham verilerin düzenli gösterimi.

##Kullanılan Teknolojiler
- Python
- Pandas
- Plotly
- Streamlit
